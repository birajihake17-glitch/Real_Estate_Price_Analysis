# Real Estate Price Analysis

## Project Overview
This project analyzes house prices using Python and data visualization libraries.

## Dataset
The project uses the King County house sales dataset.

- Original records: 21,613
- Cleaned records: 21,597
- Original columns: 22
- Columns after cleaning: 21

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Cleaning
- Removed the unnecessary index column.
- Handled missing values in bedrooms and bathrooms.
- Converted the date column to datetime format.
- Checked for duplicate records.

## Exploratory Data Analysis
- House price distribution
- Bedroom-wise average price analysis
- Living area versus house price
- ZIP-code-wise price comparison
- Correlation heatmap
- Monthly average house price trend

## Key Findings
- Average house price: $540,202.92
- Median house price: $450,000
- Minimum house price: $78,000
- Maximum house price: $7,700,000
- Three-bedroom properties were the most common among the analyzed bedroom groups.
- House prices generally increased with living area.

## Conclusion
The analysis explores how house prices vary with property characteristics and location. The findings describe the historical dataset and should not be treated as current market prices.
